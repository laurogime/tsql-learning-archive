# SQL Engineering Practice (T-SQL)

A personal repository documenting my SQL learning journey and progression toward professional Data Engineering.

This repository contains my previous practice using Microsoft SQL Server and T-SQL. It is preserved as an archive of my exercises, assignments, and technical development.

**Status:** Archived — no longer actively maintained.

## Tech Stack

- Microsoft SQL Server
- T-SQL
- Visual Studio Code
- Git & GitHub

## Repository Structure

- `practice/` — Daily SQL exercises organized by date
- `datasets/` — Reusable datasets for SQL practice
- `archive/` — Previous assignments, solutions, and reviews

## Topics Practiced

- SQL Fundamentals
- Joins and Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- Aggregations and Grouping
- Set Operators
- Date and Time Functions
- Data Quality and Validation

## Practice Approach

Practice files document SQL problems, attempted solutions, and relevant technical notes.

The focus is on developing SQL correctness, readability, logical reasoning, and an understanding of Data Engineering principles.

## Development Environment

SQL scripts were written in T-SQL and practiced using Microsoft SQL Server through Visual Studio Code.
